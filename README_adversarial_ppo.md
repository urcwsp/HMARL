# 对抗式PPO强化学习算法（VaryingDynamicsEnv环境）

这个项目实现了一个基于PPO（近端策略优化）的对抗式强化学习训练框架，用于在MetaDrive的VaryingDynamicsEnv环境中训练自动驾驶智能体。特点是采用双智能体对抗式训练方式，一个"主角"智能体负责控制车辆驾驶，一个"对手"智能体负责调整环境动力学参数以增加驾驶难度。

## 核心思想

1. **双智能体对抗训练**：
   - **主角智能体**：控制车辆行驶，目标是安全高效地到达目的地。
   - **对手智能体**：调整车辆动力学参数，目标是使主角智能体的奖励变少。

2. **零和博弈设置**：
   - 对手的奖励 = -1 * 主角的奖励
   - 这种设置迫使主角智能体学习适应对手选择的困难环境参数。

3. **动力学参数优化**：
   - 对手智能体可以调整以下参数：
     - 发动机力（max_engine_force）
     - 制动力（max_brake_force）
     - 轮胎摩擦力（wheel_friction）
     - 最大转向角（max_steering）
     - 车辆质量（mass）

## 实现细节

### 网络架构

两个智能体都使用PPO算法，包含：
- Actor网络：输出动作的均值
- Critic网络：评估状态价值
- 连续动作空间，使用对角高斯策略

### 训练流程

1. 对手智能体选择动力学参数
2. 创建具有这些参数的环境
3. 主角智能体在此环境中进行多个episode训练
4. 根据主角表现更新对手的策略（使用负的主角奖励）
5. 交替训练，重复上述过程

### 训练策略

- 在训练初期（前20轮），只训练主角智能体，让其先学习基本驾驶能力
- 之后开始交替训练，但每轮主角训练步数(4)多于对手(2)，确保主角能跟上对手的挑战

## 如何使用

### 依赖项

```bash
pip install metadrive-simulator gymnasium torch numpy
```

### 训练模型

```bash
python adversarial_ppo_training.py
```

默认训练参数：
- 总训练轮数：500轮
- 每轮主角训练步数：4
- 每轮对手训练步数：2
- 学习率：主角0.0003，对手0.001
- PPO参数：gamma=0.99, K_epochs=20(主角)/10(对手), eps_clip=0.2

### 测试模型

训练完成后，脚本会自动进行测试并渲染可视化结果。
测试过程会显示：
- 当前动力学参数设置
- 每个episode的累积奖励
- 是否成功到达目的地
- 是否发生碰撞或出界

## 代码结构

- `ActorCritic`: PPO网络架构实现
- `PPO`: PPO算法核心实现 
- `RolloutBuffer`: 经验回放缓冲区
- `AdversaryAgent`: 对手智能体实现
- `adversarial_ppo_training()`: 训练主函数
- `test_trained_agents()`: 测试函数

## 自定义调整

### 修改训练参数

可以调整以下训练参数以适应不同需求：
```python
max_epochs = 500          # 总训练轮数
max_protagonist_steps = 4  # 每轮主角训练步数
max_adversary_steps = 2    # 每轮对手训练步数
```

### 修改动力学参数范围

可以调整对手能够控制的动力学参数范围：
```python
param_ranges = {
    "max_engine_force": (100, 3000),
    "max_brake_force": (20, 600),
    "wheel_friction": (0.1, 2.5),
    "max_steering": (10, 80),
    "mass": (300, 3000)
}
```

## 优势与应用

1. **提高泛化能力**：通过对抗训练，主角智能体能够适应各种极端的车辆动力学情况。

2. **鲁棒性增强**：面对恶劣的驾驶环境（如低摩擦力、高质量、弱制动力等），智能体也能保持可靠的驾驶能力。

3. **自动化参数探索**：对手智能体会自动找出最能挑战主角的参数设置，无需手动设计困难场景。

4. **真实世界迁移**：训练出的智能体更容易适应实际车辆的动力学特性变化。
